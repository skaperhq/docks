# Support

- Use [GitHub Discussions](https://github.com/kalidasrajeev1997/docks/discussions)
  for usage questions and design proposals.
- Use [GitHub Issues](https://github.com/kalidasrajeev1997/docks/issues) for
  reproducible bugs and scoped feature requests.
- Use private vulnerability reporting for security concerns as described in
  [SECURITY.md](SECURITY.md).

Include the Docks version, Node.js version, framework, minimal reproduction,
and relevant logs with secrets removed. Support is community-driven and has no
guaranteed response time.
